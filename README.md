# John M. Kuffer — Portfolio Website

A responsive, static portfolio website designed for free hosting with GitHub Pages.

## Included
- Responsive modern portfolio layout
- Project gallery with image lightbox
- About, capabilities and contact sections
- No paid themes, plugins, database, or build process

## Before publishing
1. Replace the four sample project panels with your own photographs.
2. Put your image files in `assets/` and name them `project-01.jpg`, `project-02.jpg`, etc.
3. In `index.html`, replace the placeholder image links if using different filenames.
4. Replace `YOUR-EMAIL@example.com` with your real email address.
5. Edit the project titles, descriptions, and capabilities so they accurately reflect your experience.
6. Optionally add a PDF resume link and LinkedIn link.

## Publish free with GitHub Pages
1. Create a free account at https://github.com/join and verify your email.
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
3. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. Wait a few minutes. Your site will be at `https://YOUR-GITHUB-USERNAME.github.io`.

GitHub Pages free hosting uses a public repository. Do not upload private information, personal documents you do not want public, or a resume containing sensitive details.

## Notes
The sample artwork blocks are placeholders. They do not represent completed projects. The website uses Google Fonts when internet access is available and falls back to system fonts if not.
